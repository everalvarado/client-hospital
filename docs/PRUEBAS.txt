PRUEBAS DEL SISTEMA HOSPITALARIO DE TURNOS
==========================================

Preparación
-----------
1. PostgreSQL encendido.
2. En API:    npm run db:reset   y después   npm run dev   (puerto 3001)
3. En CLIENT: npm run dev                                   (puerto 5173)
4. Usuarios:  admin/admin123 · enfermera/enfermera123 · med001..med005/med123 · juan/paciente123 · sofia/paciente123

Resultado: OK = funcionó como se esperaba · FALLA = anotar qué pasó

PRUEBAS DE LA API (REST Client / Postman)
-----------------------------------------
Archivo: API/api.http

POST http://localhost:3001/auth/login
Content-Type: application/json

{ "usuario": "enfermera", "contraseña": "enfermera123", "rol": "enfermero" }

-> copiar el "token" de la respuesta y usarlo así:

GET http://localhost:3001/turnos?estado=Pendiente
Authorization: Bearer <token>

PATCH http://localhost:3001/turnos/1/aprobar
Authorization: Bearer <token>
Content-Type: application/json

{ "id_consultorio": 1 }
